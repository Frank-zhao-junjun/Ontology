## 1. 界面概览

```
┌─────────────┬──────────────────────────────┬──────────┐
│  业务树      │       主编辑区                │  要素库   │
│  (左侧面板)  │       (中间面板)              │  (右侧面板)│
│             │                              │          │
│  A-生产制造  │  根据选中的节点显示对应编辑器    │  搜索要素  │
│  ├─B-计划管理│                              │          │
│  │ └─C-MTS排产│  · C 详情 / EPC / 要素选择   │  E1 数据  │
│  ├─B-库存管理│  · 模块状态 / 版本历史         │  E2 行为  │
│  │ └─C-收货  │                              │  ...     │
│  └─B-质量检验│                              │          │
│    └─C-来料  │                              │          │
└─────────────┴──────────────────────────────┴──────────┘
```

### 主要区域

| 区域 | 功能 |
|------|------|
| **左侧：业务树** | 展示 A→B→C 层级，右键可新建/编辑/删除 |
| **中间：编辑器** | 根据选中的节点显示对应编辑器 |
| **右侧：要素库** | 搜索和浏览所有要素（E1–E8） |
| **顶部：工具栏** | 项目切换、保存、导出、AI 功能 |

## 2. 项目管理

### 新建项目
1. 点击顶部 **"新建项目"**
2. 填写：项目名称、描述、选择业务领域
3. 点击 **"创建"**

### 切换项目
- 点击顶部项目名称，从下拉列表中选择

### 编辑项目属性
- 在业务树顶部点击项目名称，右侧显示项目详情
- 可修改名称和描述

## 3. 业务树（A/B/C）

### 层级结构

```
项目
└── A: 价值域（ValueDomain）
    ├── 属性：名称、描述、图标
    │
    ├── B: 能力（Capability）
    │   ├── 属性：名称、描述
    │   │
    │   └── C: 场景（Scenario）
    │       ├── 属性：名称、描述
    │       └── EPC 流程（见第 4 节）
    │
    ├── B: 能力 2
    │   └── C: 场景 2
    └── ...
```

### 操作

| 操作 | 方式 |
|------|------|
| 新建 A | 在项目上右键 → "新建 A" 或使用工具栏 |
| 新建 B | 在 A 上右键 → "新建 B" |
| 新建 C | 在 B 上右键 → "新建 C" |
| 编辑 | 双击节点或右键 → "编辑" |
| 删除 | 右键 → "删除"（注意：删除 A 会同时删除其下所有 B/C/EPC）|
| 展开/折叠 | 点击节点前的箭头 |
| 搜索 | 顶部搜索框输入关键词 |

### 模块状态

每个 C（场景）都有状态标识在节点旁：
- 📝 **草稿** — 正在编辑
- ✅ **已确认** — 已发布锁定
- 📦 **已归档** — 历史版本

## 4. EPC 流程编辑

### 入口
选中一个 C（场景）后，点击中间面板的 **"EPC"** 页签。

### 编辑步骤

1. **添加步骤**：点击 "添加步骤"，输入步骤描述
2. **排序**：拖动步骤卡片上下移动
3. **删除步骤**：点击步骤右上角的删除按钮
4. **引用要素**：点击步骤中的 "选择要素" 按钮，从要素库中选择
5. **保存**：点击 "保存 EPC"

### 要素选择器

在 EPC 步骤中引用要素时：
1. 点击 **"选择要素"**
2. 弹出要素选择器，按维度筛选（E1–E8）
3. 搜索或浏览已有要素
4. 也可直接**内联新建**要素
5. 选择后自动填入步骤的 elementRef

### 自动保存

EPC 编辑支持自动保存，每步操作后自动同步。

## 5. 要素库（E1–E8）

### 入口
点击右侧面板的 **"要素库"** 页签。

### 浏览要素

| 维度 | 色标 | 内容 |
|:----:|:----:|------|
| E1 数据 | 🔵 蓝 | Entity、Attribute、Relation |
| E2 行为 | 🟢 绿 | StateMachine、Action、Transition |
| E3 事件 | 🟡 黄 | EventDefinition、Subscription |
| E4 规则 | 🔴 红 | 校验规则（字段/跨字段/聚合） |
| E5 岗位 | 🟣 紫 | Department、Position、Role |
| E6 指标 | 🟠 橙 | BusinessMetric |
| E7 约束 | ⚪ 灰 | GuardCondition、TransactionBoundary |
| E8 接口 | 🟤 棕 | DataSource、Integration、Webhook |

### 新建要素
1. 选择维度（E1–E8）
2. 点击 "新建"
3. 填写要素名称、描述和具体字段
4. 保存

### 未引用视图
要素库提供 **"未引用"** 筛选，显示未被任何 EPC 使用的要素，方便补充遗漏。

### 覆盖率 Badge
每个要素卡片上显示 EPC 覆盖率徽章：
- 🟢 已引用
- 🔴 未引用
- ⚪ 部分引用

## 6. 模块版本管理

### 三种状态

```
草稿 ──→ 已确认 ──→ 已归档
  ↑          │
  └──────────┘ (可以重新编辑为草稿)
```

### 操作

| 操作 | 说明 |
|------|------|
| **确认** | 在 C 工作区点击"确认"，锁定当前版本 |
| **取消确认** | 如需修改已确认的内容，先"取消确认"回到草稿 |
| **归档** | 废弃旧版本 |
| **版本历史** | 查看所有历史版本的变更记录 |

### 引用锁定

当要素被 EPC 引用后：
- 要素更新后，EPC 会显示 "有新版本可用" 警示
- 不强制更新，由用户决定是否同步到最新版

## 7. 校验与覆盖率

### W-EPC 警示

在 EPC 页面点击 **"校验"** 按钮，系统自动检查 17 条规则：

| 范围 | 规则数 | 示例 |
|------|:------:|------|
| 引用完整性 | W-EPC-01~05 | 要素是否存在、是否已确认 |
| 行为一致性 | W-EPC-06~08 | Action 引用是否正确 |
| 数据依赖 | W-EPC-09~11 | E1 实体绑定是否完整 |
| 事件联动 | W-EPC-12~14 | 事件起止是否正确 |
| 约束 | W-EPC-15~17 | GuardCondition 是否引用 |

警告以 ⚠️ 显示，**不阻断导出**。

### 覆盖率仪表盘

在 C 工作区点击 **"覆盖率"** 页签：

- 按 E1–E8 维度显示 EPC 引用率
- 饼图 + 进度条可视化
- 缺口分析，指导补充要素

### 交叉一致性

在 C 工作区点击 **"验证"** 页签，显示三栏：

| 栏 | 内容 |
|:--:|------|
| VE | EPC 要素一致性 |
| VM | EPC 覆盖率 |
| VX | 交叉一致性（VX-01~12） |

## 8. Excel 导入导出

### 导出 Excel
1. 在工作台点击 **"导出" → "Excel"**
2. 选择要导出的模块（默认全选）
3. 点击 "生成"
4. 浏览器自动下载 `.xlsx` 文件

导出的 12 个 Sheet：
- A 价值域、B 能力、C 场景、EPC 步骤
- E1 数据模型、E2 行为模型、E3 事件模型
- E4 规则模型、E5 岗位角色、E6 指标
- E7 约束、E8 接口模型

### 导入 Excel
1. 点击 **"导入" → "Excel"**
2. 选择之前导出的 `.xlsx` 文件
3. 预览变更内容
4. 确认导入

## 9. AI 辅助建模

### AI Draft 填充
1. 在 EPC 编辑器中，点击某个步骤的 **"AI 填充"**
2. 输入描述（如"根据库存数量自动补货"）
3. AI 自动生成 Draft 级别的要素建议
4. 审阅后确认或修改

### 上传参考文档
1. 点击 **"AI" → "上传参考文档"**
2. 支持格式：Word（.docx）、PDF、Excel、TXT、Markdown
3. AI 自动提取文档中的实体候选
4. 审阅后添加到要素库

### AI 生成模型
1. 点击 **"AI" → "生成模型"**
2. 用自然语言描述业务场景
3. AI 返回建议的 EPC 步骤和要素
4. 一键应用到当前工作区

## 10. 数据导出

### Manifest 导出
适用于对接项目2（治理平台）：
1. 点击 **"导出" → "Manifest"**
2. 选择版本和配置
3. 生成 JSON 格式的本体模型包
4. 下载或复制到项目2 导入

### 代码生成
1. 点击 **"导出" → "代码生成"**
2. 选择目标语言（Java/TypeScript）
3. 生成代码骨架包
4. 下载后导入 IDE

## 常见问题

**Q: 保存失败怎么办？**
A: 检查网络连接，本地开发环境确认 `pnpm dev` 在运行。

**Q: EPC 步骤可以有多少个？**
A: 没有硬限制，但建议单个 EPC 不超过 30 步，超过可拆分为多个子流程。

**Q: 已确认的模块怎么修改？**
A: 先"取消确认"回到草稿状态，修改后重新确认。

**Q: 要素被引用了能删吗？**
A: 不能直接删除，需要先移除所有引用后再删除。系统会提示哪些 EPC 在引用。
