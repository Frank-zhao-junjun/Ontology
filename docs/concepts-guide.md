# Ontology 本体建模工具 — 概念指南

> 面向非技术人员，用大白话解释核心概念

---

## 什么是"本体建模"？

简单说，就是把**业务知识变成机器能理解的结构**。

比如"客户下单"这个业务场景，你需要告诉系统：
- **客户**是什么？（有姓名、电话、地址）
- **订单**是什么？（有商品、数量、金额）
- **下单**的过程是怎样的？（创建订单 → 验证库存 → 确认付款 → 发货）

本体建模就是把这些东西画成一张张清晰的"业务地图"。

---

## 核心模型：A → B → C → EPC

这是整个工具的骨架，一个层层细化的漏斗：

```
┌──────────┐
│  A 价值域  │  最顶层：你关心什么业务？
│  生产制造  │  像"生产制造""财务会计""人力资源"
└────┬─────┘
     │ 
┌────▼─────┐
│  B 能力   │  中间层：需要什么能力？
│  计划管理  │  像"计划管理""库存管理""质量检验"
└────┬─────┘
     │
┌────▼─────┐
│  C 场景   │  具体层：什么场景？
│  MTS排产  │  像"MTS排产场景""来料检验场景"
└────┬─────┘
     │
┌────▼──────────┐
│  EPC 流程图     │  最底层：具体怎么做？
│ step①→step②→...│  一步一步的操作流程
└────────────────┘
```

**关系**：一个 A 下面有多个 B，一个 B 下面有多个 C，一个 C 下面有一套 EPC 流程。

---

## 八维要素库（E1–E8）

每个 EPC 步骤里会用到各种"要素"，就像做菜要用到食材和工具。八个维度：

| 编号 | 名称 | 大白话 | 举例 |
|:----:|------|--------|------|
| E1 | 数据模型 | 业务对象长什么样 | 客户（字段：姓名、电话、地址） |
| E2 | 行为模型 | 对象能做什么 | 订单可以"创建""取消""发货" |
| E3 | 事件模型 | 发生了什么 | 订单已创建 → 触发库存检查 |
| E4 | 规则模型 | 有什么规则 | 订单金额 > 1 万需审批 |
| E5 | 岗位角色 | 谁来做 | 计划员、质检员、审批人 |
| E6 | 指标模型 | 怎么衡量 | 准时交付率、库存周转天数 |
| E7 | 约束模型 | 有什么限制 | 已发货订单不能取消 |
| E8 | 接口模型 | 跟谁对接 | 对接 SAP、MES、WMS 系统 |

## 三种状态：草稿 → 已确认 → 已归档

每个模块都有生命周期：

```
📝 草稿       → ✅ 已确认       → 📦 已归档
  还在编辑中      锁定了，别人可以引用   不再使用，但保留记录
```

**为什么要有三种状态？**
- 你编辑的时候别人不能乱改 → **草稿**
- 确认后团队其他人可以用你的成果 → **已确认**
- 旧版本不删，留作历史 → **已归档**

## EPC 流程图：把业务画出来

EPC（Event-driven Process Chain）是一种画业务流程的方法：

```
[开始] → [检查库存] → [创建订单] → [确认付款] → [发货] → [结束]
              │                      │
              ▼                      ▼
         引用了 E1（数据模型）     引用了 E2（行为模型）
         "库存"实体                "付款确认"行为
```

每个步骤都可以引用要素库里的东西，实现"业务知识地图"的全局关联。

## 校验体系：帮你发现遗漏

工具自动检查你的建模有没有问题，分三类：

| 类型 | 代码 | 说明 | 举例 |
|------|:----:|------|------|
| ⚠️ 警示 | W-EPC | 可能有问题但不阻断 | "引用的要素已被更新" |
| 📊 覆盖率 | VM | 哪些要素被用了、哪些没用 | "E3 事件模型覆盖率为 40%" |
| 🔗 一致性 | VX | 不同地方的说法是否矛盾 | "A 层说是 V 系列，B 层说是 M 系列" |

**17 条 W-EPC 规则** + **22 条覆盖率规则** + **12 条一致性规则**，帮你把关。

## AI 辅助：让 AI 帮你建模

- **AI Draft**：告诉 AI "帮我创建一个客户实体"，它会自动生成建议
- **上传文档**：上传 Word/PDF/Excel，AI 从中提取实体候选
- **AI 生成 EPC**：描述一个业务流程，AI 帮你画出流程图

## 导出：把你的模型输出

建好的模型可以：
- **Excel 导出**：分 12 个 Sheet 导出，方便汇报
- **Manifest 导出**：JSON 格式，给下游系统（如项目2 治理平台）使用
- **代码生成**：生成 Java/TypeScript 代码骨架
