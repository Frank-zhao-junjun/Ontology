# 快速入门 — 5 分钟建一个本体模型

> 适用版本：Ontology Modeling Tool v3.x
> 用时：约 5 分钟

---

## 前置准备

```bash
pnpm install
pnpm dev
```

打开浏览器访问 `http://localhost:3000`，点击"进入工作台"。

---

## 第一步：创建项目

1. 在工作台页面，点击 **"新建项目"**
2. 填写项目名称（如"生产制造域"）
3. 选择业务领域（如"离散制造"）
4. 点击 **"创建"**

> 完成后你会看到一个空白的工作台，左侧是业务树，右侧是编辑区。

---

## 第二步：添加价值域（A）

1. 在左侧业务树中，点击 **"新建 A"**
2. 名称填写"生产制造"，中英文均可
3. 添加描述："覆盖计划到交付的全流程"
4. 点击 **"保存"**

---

## 第三步：添加能力（B）

1. 选中刚才创建的"生产制造"
2. 点击 **"新建 B"**
3. 名称填写"计划管理"
4. 保存

再新建一个 B："库存管理"

---

## 第四步：添加场景（C）

1. 选中"计划管理"
2. 点击 **"新建 C"**
3. 名称填写"MTS 排产场景"
4. 保存

---

## 第五步：画 EPC 流程图

1. 选中"MTS 排产场景"
2. 点击 **"EPC"** 页签
3. 点击 **"添加步骤"**，依次添加：
   - 步骤 1：接收订单
   - 步骤 2：检查库存
   - 步骤 3：生成工单
   - 步骤 4：下达生产
4. 拖动步骤调整顺序
5. 点击 **"保存 EPC"**

---

## 第六步：添加要素（可选）

1. 切换到 **"要素库"** 页签
2. 点击 **"新建要素"**
3. 选择维度 E1（数据模型）
4. 名称填写"工单"，添加字段：工单号、产品、数量、状态
5. 保存

回到 EPC 页面，每个步骤可以引用已创建的要素。

---

## 第七步：确认模块

1. 在模块状态栏，点击 **"确认"**
2. 系统会提示 W-EPC 检查结果（如果有警示可以忽略或修复）
3. 点击 **"确认发布"**
4. 模块状态变为 ✅ 已确认
