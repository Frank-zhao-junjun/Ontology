# Goal-Loop 文件模板（verbatim）

> Agent 生成 GOAL / GOALS / REPORT 时必须保留下列章节标题与字段结构。用户提供的占位内容可替换为实际值。

---

## 使用流程

1. **对齐总目标**  
   向用户确认总目标信息（目标/交付物/标准/范围/禁止/验收）

2. **生成 GOAL.md**  
   含策略选择记录 → 用户确认

3. **拆解 GOALS.md**  
   每个子目标含回溯条件+迭代预算 → 用户确认

4. **生成 REPORT.md 模板**  
   空模板 → 用户确认

5. **用户确认全部文件后，开始执行**
   - 每轮执行后更新 REPORT.md
   - 触发回溯条件时 → 报告并等待确认
   - 迭代超限时 → 停止并报告
